# Saarthi Task Automation Frontend

Vite + React + TypeScript client for the task automation backend.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Environment

`VITE_API_BASE_URL` should point at the backend API root, including `/api/v1`.

```bash
VITE_API_BASE_URL=http://localhost:5000/api/v1
```

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
